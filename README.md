# Sales Data Analysis

## Project Overview

This project focuses on performing exploratory data analysis (EDA) on a retail sales dataset to understand sales patterns across different regions, product categories, and customer segments. The objective is to extract meaningful insights from the dataset using Python-based data analysis and visualization techniques.

## Tools and Technologies

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

## Dataset Description

The dataset contains retail transaction information with the following attributes:

* Order ID
* Order Date
* Ship Date
* Customer Information
* Region and Location
* Product Category and Sub-Category
* Product Name
* Sales

These attributes allow analysis of customer purchasing behavior, regional sales performance, and product-level trends.

## Analysis Performed

The following analyses were conducted as part of this project:

* Sales distribution across different regions
* Sales comparison between product categories
* Identification of top-performing products based on sales
* Analysis of sales contribution by different customer segments
* Visualization of key patterns using charts and graphs

## Key Insights

* Certain regions contribute significantly more to overall sales compared to others.
* Some product categories dominate the total revenue generated.
* Customer segments show noticeable differences in purchasing behavior.

## How to Run the Project

1. Clone the repository.
2. Open the project folder.
3. Launch the Jupyter Notebook file (`analysis.ipynb`).
4. Run the cells to reproduce the analysis and visualizations.

## Conclusion

This project demonstrates the use of Python for performing exploratory data analysis and deriving useful insights from structured datasets. It highlights how data visualization and aggregation techniques can help uncover trends in retail sales data.
